# Espace bénéficiaire

L'espace bénéficiaire regroupe les informations personnelles, la visibilité annuaire et les marchés/lots susceptibles d'intéresser le bénéficiaire.

## Accueil

[beneficiaire-home](../../grist/page/beneficiaire-home) présente les informations principales de l'espace bénéficiaire.

## Profil

[beneficiaire-profil](../../grist/page/beneficiaire-profil) permet de gérer :

- nom ;
- prénom ;
- spécialités ;
- informations complémentaires ;
- consentements ;
- CV.

Les champs nom, prénom et spécialité sont obligatoires.

## Éligibilité

Un bénéficiaire non `Eligible` ou marqué `Doit_supprimer` ne doit plus apparaître dans les annuaires et ne doit plus avoir accès à l'espace bénéficiaire.

## Marchés actifs

[beneficiaire-marches](../../grist/page/beneficiaire-marches) affiche les lots actifs, en montrant clairement le marché parent.
